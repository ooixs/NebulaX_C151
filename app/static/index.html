Simple workflow

  1. Identify the asset and recording location.
  2. Add the original sensor files and run the check.
  3. Select a result to compare its measurements with peers in the same recording or batch.
  4. Inspect the asset and record the outcome in the review queue.

Peer comparisons are descriptive. “Outlier” means unusual within this upload, not confirmed failure.
