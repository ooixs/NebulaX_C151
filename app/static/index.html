GET STARTED

Check your first recording.

1. Choose a system and add files

Choose the train system you want to check, then add its original sensor files. Keep the filenames unchanged. For Doors, use one continuous recording. For other systems, you can add several files, up to 120 MB at a time.

2. Check the files and review the results

Select Check these files. Review the chart and results table, then read What to check next. Use these findings to help plan an inspection. An engineer must still decide whether the train is fit for service.

3. Download your results

Select Download results (CSV) to save a table you can open in a spreadsheet. For judging, select Download submission to combine your checks into predictions.zip. Example results are not included.

Which files should I use?

Why can’t I check my files?

If the app says a model is missing, ask the person setting up the app to copy the trained model file and its active_model.json record into that system’s model folder. Then open Model setup and select Check setup again. You can view example results while setup is incomplete.

Download results for judging.

Save results from your uploaded files in one ZIP file. It contains a prediction CSV for each system you have checked, in the format required by the judges.

You can upload large sets in smaller groups. If you check the same filename again, the newest result is used. For Doors, only the newest recording is included. Results for each system must use the same model version. Systems you have not checked are omitted and earn no points.
