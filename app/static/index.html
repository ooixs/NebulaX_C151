A CLEAR PATH TO YOUR FIRST RESULT

From upload to handover.

1. Choose & upload

Select the matching subsystem. Add original sensor files with unchanged names. Use one continuous Door stream, or batch test recordings for another subsystem (up to 120 MB at a time).

2. Analyze & review

Run the active model. Review the visual summary, inspect individual results, and use suggested checks to plan a maintenance review. Predictions support an engineer’s decision; they are not a release-to-service approval.

3. Export & submit

Download the exact-format prediction CSV. Analyze all four subsystems, then export a predictions.zip containing the live batches for each. Preview runs cannot enter a submission.

Recording formats

Missing a model?

Restore each trained artifact and its active_model.json to the corresponding subsystem’s model folder. Open Model registry and refresh. The app never downloads or retrains weights automatically.
