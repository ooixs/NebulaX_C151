GET STARTED

Check your first recording.

1. Choose a system and add files

Choose the train system you want to check, then add its original sensor files. Keep the filenames unchanged. For Doors, use one continuous recording. For other systems, you can add several files, up to 100 files, with a limit of 120 MB for each file. Files are checked one at a time.

2. Check the files and review the results

Select Check file, or Check files when several are selected. Review the chart and results table, then read What to check next. Use these findings to help plan an inspection. An engineer must still decide whether the train is fit for service.

3. Download your results

Select Download results (CSV) to save a table you can open in a spreadsheet. Select Download all check results to save a ZIP of your latest results for every system you have checked.

Why can’t I check my files?

If the app says a model is missing, ask the person setting up the app to copy the trained model file and its active_model.json record into that system’s model folder. Refresh the page after setup is complete. You can still review saved checks in Previous results.

Download all check results.

Save a CSV for each system you have checked, with clear column labels. The counter shows how many of the four systems have saved results.

You can upload large sets in smaller groups. If you check the same filename again, the newest result is used. For Doors, only the newest recording is included. Results for each system must use the same model version. Systems you have not checked are left out.

Submitting to the organisers?

The judging system requires its original column names, including prediction. Use this separate download for your submission.
